# AoNW cross-client contracts

This directory contains only framework-neutral evidence shared by successor
clients. Product code and client-specific tests stay with their owners.

- `fixtures/geometry/` freezes the `oddQFlatTop` presentation geometry.
- `fixtures/maps/` contains small, self-contained CI inputs.
- `fixtures/render/` defines framework-neutral semantic render probe scenarios.
- `manifests/` contains reviewed cross-client bundle contracts.
